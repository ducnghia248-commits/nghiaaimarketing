Hứng Quà FPT

Game arcade phản xạ trên web: điều khiển giỏ hứng sản phẩm FPT đang rơi, tránh vật xấu, giữ 3 mạng càng lâu càng tốt. Bộ tài liệu này mô tả game trước khi viết code.

Trạng thái: đã duyệt các quyết định GD-01 đến GD-05 ngày 06/11/2026. Chưa có code game. Các số liệu cân bằng vẫn sẽ chỉnh sau khi chơi thử.
